# FNTV iPad 1 public repository

This is an independent experimental native Objective-C/UIKit client for a user's own FNTV NAS on iPad1/iOS5.1.1. It is not an official vendor client.

- Target ARMv7/iOS5.1; use compatible APIs, MRC, bounded networking/image memory, and the legacy startup ABI.
- Preserve direct NAS communication, request signing, origin checks, Keychain token storage and the measured HLS performance improvements.
- No secrets, credentials, NAS dumps, device identifiers, private screenshots, raw logs, original APK/IPA, or proprietary SDK binaries belong in Git.
- Public artwork must be original or have documented redistribution rights. Preserve third-party notices and fixture provenance.
- Build from a user-provided SDK path; do not assume personal directories or sibling projects.
- Keep diagnostics opt-in and no broader than their documented scope. No unauthenticated remote-control service.
- Cover changed behavior with focused checks; distinguish source/fixture/build evidence from actual-device results.

During this publication task, application code changes are made by subagents only. Primary coordinates, reviews, commits, and publishes. Original validated private workspace and installed app must remain untouched.
